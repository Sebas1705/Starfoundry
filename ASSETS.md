# Third-party assets

Every font, sound or other file we bundle that we did not make is listed here, one row per file, with its source and licence. The rules are in [ADR 0037](docs/adr/0037-external-assets-policy.md); a test (`AssetsManifestTests`) fails when a file under `game/assets/fonts` or `game/assets/audio` has no row, when a row points at a missing file, when a pack has no licence text next to it, or when `game/assets/credits.tsv` (the data of the in-game Credits page) is out of date. Original art, models and sounds generated by our own code are not listed.

Columns: file (relative to the repository root), pack (the family or sound pack, one credits line), source URL, licence, author, attribution text, date added, size in bytes. Licence texts live next to each pack (`OFL.txt`, `License.txt`).
